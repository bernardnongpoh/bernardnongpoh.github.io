Web Security

Dept. of Computer Science & Engineering, IIT Guwahati

About

An introduction to the security of modern web applications — common vulnerabilities, how they are exploited, and how to defend against them. Topics include the web threat model, authentication and sessions, injection and cross-site attacks, access control, and secure development practices.
